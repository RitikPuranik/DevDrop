# DevDrop AI Studio responsive preview fix

This update:
- enlarges the mobile device frame so its top and bottom sit almost flush with the preview stage;
- keeps the real website vertically scrollable inside the phone;
- adds narrow container rules for the preview so hero type, grids, cards, navigation, artwork and CTA sections reflow at phone widths instead of behaving like a shrunken desktop layout;
- strengthens generation and edit-agent contracts so generated sites are responsive at 320/375/430/768px and desktop, with no fixed-width overflow, responsive navigation, fluid type, flexible grids, max-width media and touch-friendly controls.
