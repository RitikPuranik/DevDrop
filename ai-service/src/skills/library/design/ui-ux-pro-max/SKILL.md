Per-industry starting points for pattern, style, colour mood, typography mood and effects. They are suggestions: the user's requirements and the designSpec win, and "avoid" notes are cautions, not rules.

## SaaS (General)
- Pattern: Hero + Features + CTA
- Style priority: Glassmorphism + Flat Design
- Colour mood: Trust blue + Accent contrast
- Typography mood: Professional + Hierarchy
- Key effects: Subtle hover (200-250ms) + Smooth transitions
- Avoid: Excessive animation + Dark mode by default
- Severity: HIGH

## Micro SaaS
- Pattern: Hero-Centric + Trust
- Style priority: Motion-Driven + Vibrant & Block-based
- Colour mood: Bold primaries + Accent contrast
- Typography mood: Modern + Energetic typography
- Key effects: Scroll-triggered animations + Parallax
- Avoid: Static design + No video + Poor mobile
- Severity: HIGH
