# AI Studio theme text colors

Themes now carry semantic text colors in addition to background and surface colors:
- heading text
- body text
- muted/secondary text
- link/accent text
- inverse text where appropriate

The live preview exposes these through CSS variables, and theme cards show a small Aa/body/link sample. The AI generation design description also requires generated sites to use semantic text-color tokens rather than hardcoded conflicting text colors.
